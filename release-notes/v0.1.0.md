## v0.1.0

첫 공개 릴리스입니다. ModuleDock은 작은 위젯을 한 창에 모아 도킹·분리·정렬하고, 화면 가장자리에 붙여 자동으로 숨기는 Windows 위젯 호스트입니다.

### 추가
- 위젯 호스트: 도킹, 분리(플로팅), 드래그 정렬, 핀 고정, 상세 보기 창
- 화면 가장자리 스냅과 자동 숨기기(핸들로 다시 나타남)
- **테마 선택**: 시스템(권장) / 다크 / 라이트. 설정(⚙)에서 바꾸면 위젯도 즉시 따라갑니다. 시스템은 Windows 앱 모드를 실시간으로 따릅니다.
- 위젯 디자인 규약(`WIDGET_DESIGN_GUIDE.md`): 모든 위젯이 Host 테마(`ModuleDock.*`)를 상속
- 샘플 위젯: Clock, Counter, DiskUsage
- 자동 업데이트: 새 버전이 있으면 헤더에 ⬆ 버튼이 나타나고, 누르면 새 exe를 받아 검증한 뒤 교체·재시작합니다. 설정의 "업데이트 확인"으로 직접 확인할 수도 있습니다.

### 설치 · 업데이트
- 처음 설치: zip을 풀어 `ModuleDock.exe`를 실행합니다. 위젯은 exe 옆 `widgets\` 폴더에 들어 있습니다. (.NET 런타임 설치 불필요)
- 자동 업데이트는 `ModuleDock.exe`만 교체합니다. 번들 샘플 위젯이 바뀐 릴리스는 zip을 받아 `widgets\` 폴더까지 덮어써 주세요.
- 무결성: `SHA256SUMS.txt`의 해시와 대조할 수 있습니다.
